# Contributing

Start with [development](docs/DEVELOPMENT.md) and [architecture](docs/ARCHITECTURE.md). Keep changes scoped to the macOS Helium companion. Browser forks, Glance, Stagehand and cross-browser frameworks are outside the current scope.

Describe a concrete observed problem, the affected behavior and your validation. Preserve modifier/selection semantics, browser ownership guards, message validation and rollback. Add tests for meaningful behavioral boundaries; include actual isolated native/browser evidence when changing input, presentation or lifecycle.

Do not include personal browsing, profiles, local process telemetry, private paths, keys or raw recordings in issues or commits. Use small public or fictional fixtures. Security reports should follow [SECURITY.md](SECURITY.md).
