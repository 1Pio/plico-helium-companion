plico

Navigation for Helium, ready when you need it.

Navigation shortcuts reveal immediately. Ordinary shortcuts dismiss the navigator and continue to the page.

Shortcuts

Arrow keys also navigate. Add Shift to move tabs. Control+Tab cycles recent tabs. Escape cancels.

Hold Command or use movement shortcuts even while a page input is focused or the page is loading. Dedicated navigation takes priority; ordinary editing shortcuts and Back in a focused text field keep editing the page. Password fields protected by macOS Secure Input can block navigation shortcuts.

Stack shortcuts

Choose a digit and modifier keys for each slot, or leave it unbound. Add Shift to sort the candidate into that stack. Command+0 stays available for Helium zoom reset. All ten stacks remain available through navigation.

A blue border means a debugger was attached when the navigator opened. Plico only checks attachment metadata; it does not identify or control the debugger. Reopen the navigator to refresh. A speaker means audio is playing; a crossed speaker stays visible while muted. Command+M toggles mute and Command+W closes the candidate. The small dot marks the current page. Shift plus its configured stack shortcut sorts into a stack while selection stays behind.

Settings stay in this browser profile. Plico never changes macOS shortcuts globally.
